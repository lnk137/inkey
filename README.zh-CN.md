**打字就是文字，拖动就是笔迹。工具随动作切换，思路始终连贯。**

## 写、画、擦，随着动作自然切换

Inkey 把文字输入、手绘和临时工具放进同一套操作逻辑里，让写画之间的切换尽量无感，减少找工具、切模式对思路的打断。

- **想写就打字。** 在画布上直接输入变量或注释，无需先选择文本工具；移动指针后，可以接着在新位置输入。
- **想画就拖动。** 打完字直接拖动，即可继续绘画，包括在刚输入的文字上画线，不用先切回画笔。
- **临时工具，按住即用。** Shift＋拖动绘制当前形状；Option＋拖动临时擦除，松开 Option 就恢复原工具。

写下 `left`，拖出关系线，移动指针输入 `right`，再按住 Option 擦掉多余笔迹。输入、绘画和修正连在一起完成，工具切换融进动作里。

## 随时呼出，接着思考

在浏览器做题时，按 **⌃⌥Space** 呼出草稿，推演完再按一次回到题目。

- **需要精修时，再进入编辑。** 单击当前文字调整光标，右键文字进入可选字的完整编辑，拖动四角调整字号。
- **触控板顺手用。** 双指滚动平移，捏合缩放；Shift 拖出箭头、直线、矩形或椭圆。橡皮单击开关、右键调尺寸。
- **界面只留必要的。** 可编辑颜色预设、自定义调色、可调整大小、拖动和折叠的工具栏、可选十字轨迹，以及浮窗、常驻、全屏。
- **随时接着想。** 自动保存草稿并记住偏好，支持可编辑的 `.inkey` 文件和 PNG、PDF 导出。

Swift + AppKit。没有网页套壳、账户、遥测或第三方依赖。

## 开始使用

需要 **macOS 14+**、**Swift 6+** 和 Xcode 命令行工具。

```sh
git clone https://github.com/lnk137/inkey.git
cd inkey
./scripts/build-app.sh
open build/Inkey.app
```

Inkey 常驻菜单栏。当前版本供本机构建使用，采用本地签名，暂未提供经过公证的安装包。

## 记住这几个动作就够了

| 动作 | 效果 |
| :--- | :--- |
| **⌃⌥Space** | 呼出／收起草稿 |
| **移动指针 → 打字** | 在指针位置新建文字 |
| **拖动／⇧拖动** | 手绘／当前形状 |
| **右键文字／⌘Return** | 进入可选字的完整编辑 |
| **⇧1–4** | 按工具栏位置选择 Shift 工具（默认：箭头、直线、矩形、椭圆） |
| **⌥1–6** | 切换预设颜色 |
| **单击／右键橡皮** | 开关／调尺寸 |
| **⌥拖动** | 临时擦除 |
| **⌘E** | 导出 PNG、PDF 或可编辑草稿 |

呼出快捷键可以自定义。文字落点、工具栏显示状态、颜色、橡皮尺寸和窗口偏好都会自动记住。[查看完整操作说明 →](docs/guide.md)

## 保持轻巧，也保持可靠

```sh
swift test
```

测试覆盖写画切换、输入法、指针对齐、矢量擦除、草稿保存、导出和窗口切换。配图可通过 `./scripts/render-readme.sh` 重新生成。

欢迎[参与贡献](CONTRIBUTING.md)或[反馈问题](https://github.com/lnk137/inkey/issues)。

拖动形状按钮或预设颜色可在各自行内排序，顺序自动保存，当前工具和颜色保持不变。快捷键固定对应位置：形状 ⇧1–4，颜色 ⌥1–6。右键颜色预设可编辑或删除，在自定义调色盘中添加颜色（最多六个）；设置中可恢复默认色板。

画布始终使用十字指针；仅输入时显示文字插入光标，移动鼠标即隐藏。单击箭头或按 ⌥⌘T 折叠／展开，直接拖动箭头即可移动。折叠后只保留紧凑的箭头，不预留拖动空位。默认“聚拢收纳”让工具、颜色和分隔线一起收拢、缩入箭头，展开时再舒展开；设置中的“工具栏折叠动画”可切换到上一版“收缩淡出”，选择自动保存；箭头大小不变、无蓝色按压底色，并遵循系统“减少动态效果”设置；展开时也可拖动现有空白处移动。展开时左右拖动右上角调节柄可改变大小（85%–150%），双击恢复标准大小；右上角“…”也提供大小选项。隐藏／显示只通过“…”菜单或 ⇧⌘T 完成。大小、位置和显示状态自动保存。

右键文字后拖动边框四角可等比调整字号。默认沿用为下次输入字号；设置中可关闭沿用，也可直接指定 6–200 pt 的默认字号。呼出／收起快捷键可在设置中点击录制。

设置中可开启**开机自启动**。登录 macOS 后静默运行，只提供菜单栏和全局快捷键，不弹出草稿、设置或全屏窗口，不抢焦点。手动打开应用、按呼出快捷键或使用菜单栏即可显示草稿。开关反映系统登录项的实际状态；若需系统允许，请在“系统设置 → 通用 → 登录项”中允许 Inkey。

设置分为「常规」和「快捷键」两页。常规保留原有分组；快捷键支持 35 项操作，涵盖全局呼出、文件、编辑、画布工具、工具栏与窗口、形状和预设颜色位置。可搜索操作、点击录制、在录制时按 Delete 清除、按 Esc 取消、右键恢复单项默认，或恢复全部默认。冲突会在页内提示并保留原绑定；菜单和工具提示同步更新，重启后保留设置。文中的快捷键均为默认值，已有的自定义呼出键保持不变。

新文字框的中心对齐准星；输入、组合上屏和提交均保持中心锚点。
